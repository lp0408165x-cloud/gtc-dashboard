# GTC 客户平台 · 使用说明（全功能版）

**平台地址**：https://gtc-dashboard.onrender.com
**适用对象**：GTC 客户（出口企业、进口商、报关行）
**账号开通**：由 GTC 为您创建公司与账号，邮件发送登录信息。首次登录后请在「设置」→「安全设置」修改密码。

---

## 1. 登录与账号

- 打开平台地址，输入邮箱和密码登录
- 同一公司可开通多个账号（按套餐人数上限，由 GTC 开通），数据在公司内共享，其他公司不可见
- 忘记密码：点登录页的「忘记密码？」会打开邮件，发至 info@gtc-ai-global.com，注明登录邮箱，我们重置后回复
- 手机浏览器可直接使用；建议在电脑上上传大文件

## 2. 控制台

登录后的首页。显示：总案件数，以及按状态分列的案件数（待处理 / 审核中 / 已提交 / 已通过 / 已拒绝）、临近期限的案件提醒、最近案件。点击任一案件进入详情。

订阅用量请在「订阅管理」→「用量统计」查看。

## 3. 案件管理

### 3.1 新建案件
「案件管理」→「新建案件」（侧边栏也有「新建案件」直达入口）。分两步：

**第一步「基本信息」**，填写：
- 案件标题（必填）
- 案件类型：CF-28 信息请求 / CF-29 行动通知 / UFLPA 强迫劳动扣押 / WRO 暂扣令 / 反倾销/反补贴 / 301条款 / 扣押/没收 / 其他
- 报关号 (Entry #)
- CBP 截止日期
- 报关货值 (USD)
- 口岸 (Port of Entry)
- HTS编码
- 案情简介：任何有助于我们理解情况的背景

收到通知的日期等背景信息，请写在「案情简介」里。

**第二步「确认提交」**：核对信息后点「确认创建」。创建后直接进入该案件的「文件管理」标签，可继续上传文件。

### 3.2 案件详情页
页面顶部为案件标题和当前状态（待处理 / 分析中 / 需专家介入 / 专家处理中 / 审核中 / 已提交CBP / 合规通过 / 已结案 等）。如需删除案件，请联系我们。下方分标签：

| 标签 | 内容 |
|---|---|
| 案件信息 | 案件基本信息（标题、类型、报关号、口岸、货值、HTS 编码、CBP 截止日期、法律依据），可编辑 |
| 文件管理 | 上传、下载、删除文件，以及预处理、分类抽取、一致性校验、UFLPA 扫描（见第 4、5 节） |
| 案件分析 | 文件校验分析、分析师风险分析、UFLPA 黑名单扫描（见第 5 节） |
| 专家介入 | GTC 专家留言、补件要求、回复 |
| 工作流 | 七个阶段的进度与每个阶段的完成条件 |
| 提交记录 | 向海关提交材料的日志（见第 6 节） |

「工作流」标签中的七个阶段：**客户需求与风险初评 → 合同准备与签署 → 执行计划与启动会 → 文件审阅与缺口分析 → 证据包整合定稿 → 交付与客户培训 → 确认与案件关闭**。当前阶段高亮，每个阶段显示已完成 / 进行中 / 受阻 / 待开始 / 已跳过。

### 3.3 案件列表
可按状态筛选（全部状态 / 待处理 / 审核中 / 已提交CBP / 合规通过 / 已拒绝）；搜索框可搜索案件名称或 CBP 编号。

## 4. 文件管理

「文件管理」标签分上下两部分：

- **证据清单**：按案件类型列出所需证据项，逐项上传，并显示「证据完成度」。新案件会先显示「首次资料提交」面板，传齐必需资料后可点「识别案件类型」，结果显示「可以立案」或「尚无法立案」及 CBP 关注点
- **拖拽上传区**：拖拽文件到此处，或点击选择文件。支持 PDF、图片、Word 等格式；单个文件建议不超过 50 MB

上传注意事项：
- 需要按证据类型归档的文件，请在上方证据清单对应的项目里上传
- 建议命名：`类型_编号.pdf`，例如 `发票_INV2026-001.pdf`
- 扫描件请保证清晰、方向正确；多页文件合并为一个 PDF
- 每个已上传文件可「预处理」「分类抽取」「下载」「删除」；删除后不可恢复

## 5. 案件分析工具

分析工具分布在三处：「文件管理」标签（5.1、5.2、5.4、5.5）、「案件分析」标签（5.6），以及侧边栏的独立页面「单证核查」（5.3）。

### 5.1 预处理
「文件管理」标签，在文件行点「预处理」：对该文件做文字识别与文本提取，扫描件也能读取。上传后不会自行运行，需要逐个文件点击。

### 5.2 分类抽取
「文件管理」标签，在文件行点「分类抽取」：识别文件类型（28 类）并抽取关键字段：收发货人、发票号、日期、金额、币种、数量、重量、箱号、封号、原产地等。

### 5.3 单证核查
侧边栏「单证核查」页面（不在案件详情内）。点击或拖拽上传单证后运行核查，对提单、发票、装箱单、原产地证等的关键字段交叉比对，每一项标为：
- ✅ 一致
- ⚡ 不一致（列出两边的值，不判对错）
- ⚠️ 待核实（字段缺失或需人工确认）
- ➖ 不适用

报告包含「核心 10 项核对」和七个核查组，另附日期逻辑链检查（发票日、原产地证日、装船日先后关系）。核查结论分三档：可放行（全部一致）/ 需澄清后放行 / 存在硬伤须修正。点「导出报告」可下载双语 Word。

### 5.4 一致性校验
「文件管理」标签，点「一致性校验」：检查跨文件矛盾，共 8 项——卖方名称、买方名称、发货人与卖方、收货人与买方、箱号、发票金额与申报金额、原产地、重量——列出问题清单。

### 5.5 UFLPA 扫描
「文件管理」标签，点「UFLPA 扫描」：将文件中出现的供应商、地址、实体名与 UFLPA 实体清单比对，标记命中项。

### 5.6 案件分析标签
「案件分析」标签有三项：
- 「文件校验分析」：综合已处理文件给出风险等级、已处理文件数、一致性评分（满分 10）与发现的问题
- 「分析师风险分析」（已分析过的案件显示为「重新分析风险」）：给出案件风险评分与说明
- 「UFLPA 黑名单扫描」：与「文件管理」标签的「UFLPA 扫描」相同，结果显示在本标签

### 5.7 申诉书与回复报告
针对 CF-28 / CF-29 等通知的申诉书与回复报告，由 GTC 专家在平台内起草。申诉书草稿形成后会显示在「案件分析」标签中，供您查看。平台不会直接向海关提交任何材料。

## 6. 提交记录

案件详情「提交记录」标签，记录每一次向海关提交的材料。点「记录提交」新增，填写：提交日期、提交方式（ACE系统 / 邮件 / 快递/邮寄 / 传真 / 其他）、提交主题、收件方（CBP联系人）、CBP参考号、状态、提交文件清单、备注。

状态：已提交 / CBP已确认 / 等待回复 / CBP已回复 / 已结案，可在列表中直接切换。客户账号也可以新增记录和修改状态。

## 7. 供应链审查

「供应链审查」页面：上传供应链追溯文件（采购合同、原料发票、生产记录、供应商声明等），系统按完整性、一致性、缺失文件三个维度出具审查意见，用于 UFLPA 追溯或客户尽调。支持大体量 PDF。已完成的审查在「历史审查」中查看和下载。

## 8. 供应商扫描

「供应商扫描」页面：输入一个或多个供应商名称，与 UFLPA 实体清单比对，输出命中与相似项，显示相似度、列入日期和匹配详情。用于新供应商准入或定期复核。

## 9. 罚没应对

「罚没应对」页面：列出罚没类案件（案件编号、进口商 / 描述、口岸 / HTS、截止日期、状态），可搜索案件编号或进口商。

新建罚没案件时填写：进口商名称、CBP 案件编号、收到通知日期、进口口岸、HTS 归类编码、货物品类描述、申报货值 (USD)、CBP 引用法条、时间线描述、货权关系说明、货款支付状态、货值是否变更及原因、CBP 违规历史、补充信息。

案件详情分五个标签：分析 / 文件清单 / 申诉策略 / 关键问题 / 报告导出。应对思路见「申诉策略」标签。

## 10. 关税计算器

「关税计算器」页面：输入产品描述（必填）、选择原产地，可选填用途，点「计算关税」。结果显示 HTS 编码、关税税率构成（基础税率、Section 301、Section 232、AD/CVD 等）与估算总税率，最近的查询保留在「最近查询」中。

结果为税率估算，供参考，正式申报以海关裁定为准。

## 11. 光伏税负测算

「光伏税负测算」页面：按原产国测算光伏电池片与组件的各层税负构成，可将测算结果记入对应货件；结果为估算，正式申报以海关裁定为准。

## 12. 货件通道

「货件通道」页面：按货件管理一票货的单证与流转——出口方可新建货件、上传单证并运行核查，进口方查看分配给本公司的货件，接受或退回，并登记报关与放行。

## 13. 数据分析

「数据分析」页面：本公司案件统计与风险概览——案件总数、已完成案件、高风险案件、平均风险分；风险分布（高风险 ≥70 / 中风险 40–69 / 低风险 <40 / 未评估）；案件列表（HTS 编码、状态、风险分、创建时间）。

## 14. 资料库

「资料库」页面（页内标题「合规资料库」）：按分类浏览——全部 / UFLPA合规 / CBP应对 / AD&CVD / 关税政策。每份资料标注所需套餐（基础版 / 专业版 / 企业版），按套餐权限下载；未开通的资料显示锁定标记。

## 15. 培训中心

「培训中心」页面：在线课程，按分类筛选（全部 / UFLPA / CBP / 审计 / 入门）。在课程页直接报名，按课时学习，完成后可参加考试并获取证书。

## 16. 订阅管理

「订阅管理」页面分三个标签：
- **套餐方案**：免费试用 / 基础版 / 专业版 / 企业版，功能与配额见页面；可选月付或年付
- **用量统计**：本月各项用量（分析次数、团队成员等）
- **账单记录**：交易号、金额、方式、时间、状态（待支付 / 已支付 / 失败 / 已退款）

付费方式：**对公转账**（微信支付、支付宝页面显示「即将支持」）。如需付费，请联系 info@gtc-ai-global.com 获取收款信息；转账后请将付款凭证发送至同一邮箱，我们确认到账后开通或续期。

## 17. 设置

「设置」页面分四个标签：
- **个人信息**：修改姓名。登录邮箱不可自行修改，需要变更请联系我们
- **安全设置**：修改密码（需输入当前密码，新密码至少 8 位）
- **公司信息**：公司 ID、注册时间、账户状态等
- **线路**：中国大陆访问较慢时可切到「中国加速」线路，切换后页面自动刷新；该设置只保存在当前浏览器

## 18. 在线咨询

页面右下角「在线咨询」浮窗：解答平台使用问题与合规常见问题，可直接点选浮窗里「快速提问」下的常见问题；涉及具体案件的问题请在案件内「专家介入」留言，或邮件联系。

---

## 常见问题

- **上传失败**：检查文件大小和格式；网络不稳定时改用电脑端；仍失败请邮件联系并附文件名
- **核查报告显示"待核实"很多**：通常是扫描件不清晰或字段未被识别。可先对该文件重新「预处理」和「分类抽取」后再核查
- **看不到某个案件**：案件仅本公司账号可见；请确认登录账号所属公司
- **手机使用**：浏览器打开平台地址即可，功能与电脑端一致
- **大陆访问慢**：在「设置」→「线路」切换到「中国加速」
